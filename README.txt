CALCULATOR (vault) - Android project

1. Create a new GitHub repository and upload everything from this folder (drag the "app" folder itself).
2. Create the file .github/workflows/build-apk.yml in the GitHub web editor (copy it from this project).
3. Actions tab -> wait for the green tick -> Artifacts -> Calculator-APK -> download and install app-debug.apk.

Default secret passcode: 1234 (type it in the calculator and press =). Change it in Vault > Settings.
